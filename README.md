Entry for the [make.fun One-Liner Laugh Lab bounty](https://make.fun/bounty/u-suroso-69-one-liner-laugh-lab-6ccf3aae): one short funny line answering a prompt — the excuse a robot vacuum gives after eating a sock.

> Dear judge, I didn't eat the sock — I was taste-testing it for the washing machine, and it failed the audition: chewy, linty, no stage presence.

Run with `node main.ts`. It writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) after a self-check (one line, 1–200 characters).
